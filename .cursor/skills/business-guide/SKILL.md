# Business Guide

Translates technical documentation and specs to business-friendly language for stakeholders.

## When to Use

- Presenting to non-technical stakeholders
- Executive summaries
- Stakeholder communications

## Instructions

1. Read technical content
2. Extract key points, outcomes, risks
3. Rewrite in plain language; avoid jargon
4. Use analogies and business context where helpful
