# Refine README

Turn a default README into a best-in-class, project-specific README.

## Primary Goal

Get users from "What is this?" to "App running locally" in under 60 seconds.

## Key Instructions

1. **Value prop first** — One-sentence blockquote explaining what this does
2. **Visual Proof** — Embed live demo link or screenshot from `public/`, `e2e-results/`, `docs/images/`
3. **Quick Start** — Single copy-paste code block: install, configure, run (all in one block)
4. **Collapsible details** — Features, env vars, scripts, deployment go in `<details>` tags
5. Clean, copy/paste-safe commands (no inline comments in code blocks)

## Context to Use

- Repo code and structure, existing README, CLAUDE.md, BUILD_LOG.md, package files

## Usage

`/refine-readme` on the project README
