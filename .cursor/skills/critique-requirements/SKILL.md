# Critique Requirements

Structured feedback workflow for requirements documents (PRDs, Builder Briefs).

## When to Use

- Reviewing a draft PRD or Builder Brief
- Before finalizing requirements
- Quality check on requirements completeness

## Instructions

1. Read the requirements document
2. Apply critique framework (clarity, completeness, consistency)
3. Provide structured feedback with actionable recommendations
4. Identify gaps, ambiguities, or improvements

See [REFERENCE.md](references/REFERENCE.md) for full critique criteria.
