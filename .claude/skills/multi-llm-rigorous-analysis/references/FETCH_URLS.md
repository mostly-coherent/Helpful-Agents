## Instructions for Agent

**Before fetching:** Read the source document and extract key themes, entities, and search-relevant terms. Use these to guide which content is relevant.

1. Use `mcp_web_fetch` (or equivalent) to fetch each URL.
2. Extract and save relevant excerpts—prioritize content that relates to the themes extracted from the source (e.g., moats, platforms, AI disruption, creative tools, enterprise software).
3. If a URL returns 404 or fails, skip and continue. Note which URLs were unavailable.
4. Compile the fetched content into a "Research Summary" section for use when writing the critique.
5. Cite specific articles with provenance: [Title](URL) — excerpt or summary.
