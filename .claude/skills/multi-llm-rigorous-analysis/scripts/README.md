# Multi-LLM Analysis Scripts

## Model IDs

Edit `config.json` to update model names as new versions release. Target models:

- **Sonnet 4.6** → `anthropic/claude-sonnet-4-*`
- **Opus 4.6** → `anthropic/claude-opus-4-*`
- **GPT 5.3** → `openai/gpt-5` or `openai/o1` (when available)
- **Gemini 3.1 Pro** → `google/gemini-2.5-pro` or latest (when available)

Check [LiteLLM docs](https://docs.litellm.ai/docs/providers) for current model IDs.
