# Workspace Privacy

Prepares workspace for sharing — removes PII, private paths, and sensitive content.

## When to Use

- Before pushing to public repo
- Sharing workspace with others
- Preparing for open-source

## Instructions

1. Scan for PII (emails, paths, account names)
2. Identify private/sensitive files
3. Suggest replacements or redactions
4. Generate report of changes needed
